Puedes guardar una clave de Gemini para incluirla en el HTML descargado o publicado. La clave no queda cifrada: cualquier visitante podrá verla y usarla. El límite de 10 consultas diarias solo se aplica en cada navegador y se puede saltar. Para proteger la clave y limitar el uso de verdad, configura la función de Firebase.

Clave guardada en este navegador. Para compartirla, descarga o publica el HTML actualizado: la clave quedará visible para todos los visitantes y no estará cifrada.

Obtén una clave en Google AI Studio ↗. Al descargar o publicar el HTML, la clave se incluirá en texto legible.

Si aun así la publicas, restringe la clave en Google Cloud al dominio de tu sitio y a la API de Gemini. Esto reduce algunos usos externos, pero no oculta la clave ni impide que visitantes la usen desde tu página.

Alternativa recomendada: configura la URL HTTPS de la función aiSearch. La clave permanece como secreto en Firebase y el límite local no sustituye controles de cuota del proveedor.
